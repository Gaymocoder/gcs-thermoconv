# gcs-thermoconv

Переводит температуру из градусов Цельсия в Фаренгейты.

Запуск: `python3 thermoconv.py`

Пример:

```
Температура в °C: 36,6
36.6 °C = 97.88 °F
```

Температуру можно ввести и в Фаренгейтах: `98F`.

| Шкала | Ввод | Вывод |
|---|---|---|
| Цельсий | `37` | да |
| Фаренгейт | `98F` | да |
| Кельвин | — | да |
